# STYLE / ARCHIVE

Визуальный архив и поисковый индекс художественных стилей (тегов `@artist`) для моделей **AM Preview**, **OPUS** и **SKY**.
Статический сайт без бэкенда, публикуется через GitHub Pages.

## Запуск локально

```bash
python3 -m http.server 8000      # в корне репозитория
# открыть http://localhost:8000
```

Сборки нет: что лежит в репозитории, то и работает.

## Структура

```
index.html                 единственная страница
style.css + *-v004.css     стили (базовый + слои «поверх»)
app.js                     ядро: загрузка данных, сетка, поиск, вьювер
*-v003.js, *-v004.js       модули, подключаемые поверх app.js (см. docs/INVENTORY.md)
data/                      все данные сайта (JSON)
media/                     картинки
tools/                     скрипты обслуживания данных
tests/                     автоматические проверки
docs/                      заметки о состоянии проекта
```

### Данные (`data/`)

| Файл | Что это |
|---|---|
| `archives.json` | список архивов и их заявленные счётчики (используют скрипты, **сайт его пока не читает**, см. docs/INVENTORY.md) |
| `styles.json`, `opus-styles.json`, `sky-styles.json` | записи стилей: `id`, `name`, `presets` (`main`/`alt`), `media`, `published_at` |
| `media.json`, `opus-media.json`, `sky-media.json` | media-id → пути к файлам и размеры. `src` — полный размер (вьювер), `thumb` — миниатюра (сетка) |
| `supported.json`, `opus-supported.json` | полный список имён, которые понимает модель |
| `danbooru.json` | полный экспорт данных Danbooru (**сайт его не грузит**, это исходник для скрипта) |
| `danbooru.min.json` | облегчённая версия, которую грузит сайт. Генерируется `tools/slim_danbooru.py` |

### Медиа (`media/`)

| Папка | Назначение |
|---|---|
| `web/` | AM, полный размер для вьювера (по длинной стороне до 1200 px, WebP) |
| `thumb/` | AM, миниатюры для сетки (560 px по ширине) |
| `opus/`, `sky/` | OPUS и SKY (пока без отдельных миниатюр) |
| `original/` | убрана из рабочего дерева (лимит Pages 1 ГБ). Оригиналы лежат в истории git: `git checkout ccb9ed44 -- media/original` |

## Проверки

Перед каждым релизом:

```bash
python3 tools/audit_data.py        # целостность данных (код 1 = есть ошибки)
python3 tests/smoke.py             # сайт открывается и работает (нужен playwright)
```

Один раз для смоук-теста: `pip install playwright && playwright install chromium`.

## Инструменты (`tools/`)

| Скрипт | Что делает |
|---|---|
| `audit_data.py` | проверяет данные: ссылки, файлы, счётчики, дубли |
| `build_thumbs.py` | дорисовывает недостающие миниатюры и прописывает их в `media*.json` (`--archive am\|opus\|sky\|all`) |
| `slim_danbooru.py` | строит `danbooru.min.json` из `danbooru.json` |

## Правила, которые стоит соблюдать

- **`id` стиля не менять и не переиспользовать.** По нему хранится «Saved» у посетителей в браузере.
- Новые изображения всегда сопровождать миниатюрой (`build_thumbs.py`), иначе сетка загрузит полный файл.
- После любой правки данных запускать `audit_data.py`.
- Скрипты `tools/` запускаются из корня репозитория.
