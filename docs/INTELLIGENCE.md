# Intelligence 0.3.0: эмбеддинги стилей

Цель: «похожие стили», умный поиск и автоматические метки. Сначала нужно выбрать модель, и выбирать по измерениям, а не по репутации.

## Что мы проверяем

Одна картинка стиля содержит и манеру художника, и случайное содержание (персонаж, поза, фон). Обычные модели
(CLIP-семейство) смешивают их. Нам нужна модель, у которой картинки одного художника оказываются рядом, даже когда
на них разные персонажи.

Проверка автоматическая: у стилей с 2+ превью берётся одна картинка и ищется её стиль среди всех остальных
(остальные превью этого стиля в запрос не входят). Это `hit@1/5/10` в отчёте. Сверх цифр отчёт даёт контактные листы
«стиль и 8 ближайших соседей», чтобы оценить результат глазами.

Кандидаты (все с Hugging Face, ставятся автоматически): `siglip2` (понимает текст, нужен для умного поиска),
`dinov2` (чисто визуальный) и запасной `clip`. Модель CSD (Contrastive Style Descriptors, специально для стиля)
отдельно: её веса в репозитории помечены авторами как имеющие расхождение с цифрами статьи, а код загрузки
требует их репозитория, поэтому подключим её, только если siglip2 и dinov2 окажутся слабыми.

## Что сделать на ПК (Windows, PowerShell, из корня репозитория)

1. Свежий код: `git pull` на ветке `feat/embeddings` (или после мержа на `main`).
2. Python 3.10+ и драйвер NVIDIA должны быть. Поставить torch с CUDA по команде с pytorch.org
   (Stable, Windows, Pip, CUDA 12.x), затем проверить:
   ```
   py -c "import torch; print(torch.__version__, torch.cuda.is_available())"
   ```
   Должно быть `True`. Если `False`, дальше не идти: считаться будет на процессоре, это часы.
3. Остальное: `py -m pip install -r requirements-embed.txt`
4. Проба скорости на 200 картинках (скачает модель, это несколько ГБ; если Hugging Face не открывается, включи VPN):
   ```
   py tools\embed_styles.py --archive am --model siglip2 --limit 200
   ```
   Скрипт сам печатает «картинок/с». Это число нужно мне, чтобы оценить полный прогон.
5. Полный прогон AM для двух моделей (можно прерывать Ctrl+C и запускать снова, досчитается недостающее):
   ```
   py tools\embed_styles.py --archive am --model siglip2
   py tools\embed_styles.py --archive am --model dinov2
   ```
6. Оценка:
   ```
   py tools\embed_eval.py --archive am --models siglip2,dinov2 --samples 12
   ```
   Пришли мне `reports\embed\am.txt` и два файла `reports\embed\am.siglip2.png`, `am.dinov2.png`, а также
   число «картинок/с» из шага 4. Файлы в `embeddings\` и `reports\` в git не попадают.

OPUS и SKY считаем после выбора модели.

## Что будет дальше (после выбора модели)
