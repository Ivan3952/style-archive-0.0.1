# Тексты интерфейса: что и как переписано

Правила, по которым переписано (чтобы новые тексты не скатывались обратно):

- короткие предложения, без канцелярита («доступных», «осуществляется», «функционал»);
- без служебных подсказок для разработчика в сообщениях посетителю («запустите через HTTP-сервер»);
- без обращения на «вы» и «ты»: инфинитив или безличная форма;
- без конструкций «это не X, а Y» и перечислений из трёх слов ради ритма;
- название раздела и кнопки не меняем без причины: к ним привыкли.
