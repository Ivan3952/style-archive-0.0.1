# Как добавлять новые стили (ежемесячное обновление)

Скрипт `tools/import_telegram.py` берёт экспорт Telegram-канала и дописывает новые стили в архив **AM**.
OPUS и SKY пока обновляются вручную: у них другая схема id.

> **Статус правил.** Разбор подписей (хештег, `@художник`, `main`/`alt`) и сопоставление картинок с художниками
> выведены из текущих данных, а не проверены на настоящем экспорте. Первый запуск делать как пробный и
> сверять отчёт глазами. Если разбор расходится с реальностью, правится регулярка в `parse_caption`.

## Порядок

1. Telegram Desktop → канал → «Export chat history» → формат **JSON**, включить **Photos**.
2. Посмотреть, как разобраны первые посты (ничего не пишет):

   ```bash
   python3 tools/import_telegram.py путь/к/ChatExport --inspect 20
   ```

3. Пробный прогон (ничего не пишет, печатает отчёт):

   ```bash
   python3 tools/import_telegram.py путь/к/ChatExport
   ```

4. Если отчёт верный, записать:

   ```bash
   pip install pillow
   python3 tools/import_telegram.py путь/к/ChatExport --apply
   ```

5. Проверки и коммит:

   ```bash
   python3 tools/audit_data.py
   python3 tests/smoke.py
   git add data media && git commit
   ```

Картинки лежат вне `dist`, поэтому после деплоя кода медиа уходит на хостинг отдельным шагом workflow.

## Что делает скрипт

| Случай в посте | Результат |
| --- | --- |
| 1 художник, k картинок | одна запись с k картинками, id = номер первого сообщения |
| n художников, n картинок | n записей `<id>-1` … `<id>-n` |
| n художников, n+1 картинок | первая картинка общая (`reference_media`), остальные по порядку |
| другое соотношение | пост **не импортируется**, попадает в раздел «Сомнительные» отчёта |
| нет `main`/`alt` | не импортируется (арт перегенерируется) |
| стиль с таким названием уже есть | картинки добавляются к старой записи (самой свежей), ставится `updated_at` |

Повторный запуск безопасен: `data/import_state.json` помнит границу и обработанные посты.
Чтобы переимпортировать с нужного места, укажите `--from-id НОМЕР`.

## Проверка самого скрипта

```bash
python3 tests/test_import.py
```

Тест работает на выдуманном экспорте во временной папке, реальные данные не трогает.
